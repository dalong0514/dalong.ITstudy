## 0401Summary-and-next-steps

I hope you've enjoyed this overview of Claude Code. Before we finish up, I want to give you some advice on where to go from here.

希望您喜欢对 Claude Code 的介绍。在我们结束之前，我想给您一些关于接下来如何探索的建议。

First, keep in mind that Claude Code is constantly changing and in active development. So keep an eye on the homepage of Claude Code—I've got the address to it right there—and watch for new features and techniques to come out.

首先，请记住 Claude Code 正在不断更新和积极开发中。因此，请密切关注 Claude Code 的主页 —— 我已将地址放在这里了 —— 并留意新功能和新技术的发布。

Secondly, I really recommend you experiment. There's a lot of different ways to customize Claude Code and really tailor it to your particular use case. Try to author some custom commands or put extra instructions in your Claude indie file, and also try out a couple of different mcp servers beyond the ones we looked at inside this course.

其次，我强烈建议大家多进行实验。Claude Code 有许多不同的定制方法，可以真正根据你的特定用例进行调整。你可以尝试编写一些自定义命令，或者在你的 `Claude indie file` 中添加额外的指令，还可以尝试课程中介绍的那些以外的 `mcp` 服务器。

Finally, automate. Take a look at the GitHub integration and think of some different common tasks that you go through all the time, and think of some ways you can delegate those to Claude automatically based upon events that occur inside of your GitHub repository.

最后，自动化。你可以看看 GitHub 集成功能，思考一些你平时经常执行的常见任务，然后想想如何根据 GitHub 仓库中发生的事件，将这些任务自动交给 Claude Code 来处理。

Well, again, I hope you enjoyed this course, and enjoy your time working with Claude Code.

那么，再次，我希望您喜欢这门课程，并祝您在使用 Claude Code 的过程中一切顺利。
