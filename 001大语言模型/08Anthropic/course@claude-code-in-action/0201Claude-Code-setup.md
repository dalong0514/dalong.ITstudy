## 0201Claude-Code-setup

[Claude Code setup](https://anthropic.skilljar.com/claude-code-in-action/301614)

Time to get Claude Code set up locally!

Full setup directions can be found here: https://docs.anthropic.com/en/docs/claude-code/setup

In short, you'll need to do the following:

1 Make sure you have NodeJS installed. If you're not sure if you already have it installed, you can get an installer at https://nodejs.org/en/download

2 At your terminal, run npm install -g @anthropic-ai/claude-code

3After installation, run claude at your terminal. The first time you run this command you will be prompted to authenticate

If you're making use of AWS Bedrock or Google Cloud Vertex, there is some additional setup:

Special directions for AWS Bedrock: https://docs.anthropic.com/en/docs/claude-code/amazon-bedrock

Special directions for Google Cloud Vertex: https://docs.anthropic.com/en/docs/claude-code/google-vertex-ai
