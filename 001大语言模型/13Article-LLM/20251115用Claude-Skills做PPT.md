## 20251115用Claude-Skills做PPT

[用Claude Skills做PPT，真实演示](https://mp.weixin.qq.com/s/Fp2y21F4a7UP1zwRfnsCtw)

我是小排。今天我要解决的一个真实问题：本周末我要做两天一夜的线下课，要做 PPT。

### 面对的挑战

整整两天一夜啊！那就意味着，我需要做一个超越 200 页的 PPT！

我已经有讲义的文字稿了，需要分段把讲义文字变成 PPT 设计。

每一页内容都需要自己打磨，无法靠 gamma 或者 Manus 等 AI PPT 工具一把梭。

每一页内容的风格要一致，审美要高级。

PPT 模板是给定的，必须要符合模板风格。

正好，现在有了 Claude Skills，上述问题就简单了。

下面演示我的实际工作过程。

### 整体思路

1、制定风格：在 Claude 里聊天，给出我的要求和 PPT 模板的风格，让 Claude 试出我满意的风格。

2、解决粘贴到 PPT 模板问题：使用透明 PNG。让 Claude 输出的卡片有「一键变成透明 PNG」的功能，这样粘贴到 PPT 里，可以把背景透出来。

3、解决稳定性问题：调试完成后，让 Claude 把刚才的所有要求封装为一个 Skill。以后新开窗口，通知 Claude 用 Skill 来创建单页。

### 制定风格

让我先选取了模板风格，纯粹文字和 Claude 对话。

```
核心功能：创建透明背景的PNG图片，专门用于PPT演示
关键要求：
1.透明背景-这是最重要的，因为要叠加到PPT背景上
2.2:1横版比例-2000x1000像素
3.苹果风格设计-简洁、现代、留白充足
4.优质中文字体-需要找到美观的中文字体
5.配色方案-从你的图片中我看到：
- 主色：青色/Teal(#00BCD4或类似)
- 辅助色：白色、深灰色文字
- 强调色：青色标签背景
典型使用场景：
- 信息图表（像你上传的"AI编程前置准备"）
- 分类说明
- 功能展示
- 列表呈现
```

刚出来的第一版，我不喜欢，如下图所示。不过没关系，我可以继续和它聊天调整，直到满意为止。反复打磨后，看到这样的效果，我感觉可以接受了。

### 变成 Skill 风格

打磨完成后，告诉 Claude：变成一个 Skill。它会继续引导我们。

记得下载安装。

不知道如何安装的同学，请继续复习上节课 [技术圈吹爆的 Claude Skills，小白用起来比程序员还爽](https://mp.weixin.qq.com/s?__biz=MzI1MTUxNzgxMA==&mid=2247499243&idx=1&sn=f8750d2e3e47f51144cd695ac1337562&scene=21#wechat_redirect)

### 使用 Skill

新开一个聊天窗口，告诉它，用 Skill 来设计。

```
用ppt-design-generator做一页，主题是：为什么Vibe Coding推荐选择NextJS?
下面是我要讲的内容的文字版本，你可以稍微做发挥。
为什么要选择 Next.js
一句话总结：Next.js特别适合小团队、一人公司、Vibe Coding,因为它是被使用最广泛的全栈框架。
我发现，从2023年起，新冒出头的AI产品，超过80%都是Next.js做的！包括chatpdf.com这种小团队产品，也包括lovable.dev这样的大团队产品！
为什么会出现这种情况呢？
在以前的互联网公司，我们提到“程序员”的时候，至少包括三种不同的程序员：前端程序员、服务端程序员（后端程序员）、算法程序员。他们一般分属于三个不同的团队。他们一般在产品经理/项目经理的管理下，进行协同工作。
对于大公司来说这很好。但是对于小公司、一人公司来说，这样的架构未免有点太臃肿。这正是Next.js在今天大行其道的原因——在Next.js里，我们可以只用一种语言、一个项目，同时搞定前端开发和服务端开发。
```

它可以稳定发挥。

怎么样？是不是既符合苹果的设计风格、又有我要求的主题颜色？点击「复制透明 PNG」把透明 PNG 粘贴到模板里，感觉挺合适的！

现在，如果你启用 canvas-design，Claude 会调用代码来画图，做出来的不是 HTML，而是 PNG。
