# Translation Prompt

## Task
Translate the article "Using Claude Code: The Unreasonable Effectiveness of HTML" from English to Simplified Chinese (zh-CN).

## Context
This is a blog post by Thariq, a member of the Claude Code team at Anthropic. He advocates for using HTML instead of Markdown as the output format for AI coding assistants. The tone is conversational, enthusiastic, and first-person. The title alludes to Eugene Wigner's famous 1960 essay "The Unreasonable Effectiveness of Mathematics in the Natural Sciences."

## Target Audience
General readers — people interested in AI tools and productivity. Not all are developers, so technical terms need brief annotations on first occurrence.

## Style
Storytelling — engaging, flowing narrative that draws readers in. Preserve the author's personal voice, enthusiasm, and emotional conviction (especially around "joy" and "feeling in the loop"). Use natural Chinese sentence patterns; restructure freely for flow.
